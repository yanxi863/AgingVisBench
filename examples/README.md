# Synthetic examples

本目录只包含为接口演示而编造的结构和数值，不包含真实参与者、私有图像、真实模型输出或论文行级数据。

- `sample_manifest.csv`：图像发现阶段的字段示例。
- `sample_stats_ready.csv`：stats-ready 字段的极小示例。
- `sample_reliability.csv`：agreement / Cohen's kappa 的测试输入。
- `pipeline.synthetic.yml`：指向微型 synthetic corpus 的 dry-run 配置。
- `sample_corpus/`：一张无人物、无身份信息的程序化占位图，只用于 discovery/dry-run。

这些文件**不能**复现或支持 `reports/` 中的 V0.5 数值结论。
