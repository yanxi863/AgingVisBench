# 即梦模型风险画像

**Model Risk Profile: Jimeng / 即梦**

## 1. 总体画像

即梦是 AgingVisBench V0.5 中老龄表征最集中、最家庭化和室内化的模型之一。它并不是简单让老年人“不行动”，而是将老年人高度放入家庭、室内、独处、食物准备、阅读和家务维护模板。

核心模式可概括为：

> **domestic interiorization + solitude + maintenance-oriented ageing**

## 2. 主要风险维度

| 维度 | 风险判断 | 证据置信度 | 说明 |
|---|---|---|---|
| 发展导向行为 | 偏见风险 | 高 | 老年组发展导向行为明显低于年轻组 |
| 科技生活符号 | 偏见风险 | 高 | 老年组现代性符号显著降低 |
| 传统文化符号 | 刻板化风险 | 高 | 老年组传统文化符号显著增加 |
| 家庭化/室内化 | 偏见风险 | 高 | 老年组 home 和 indoor 高度集中 |
| 独处化 | 偏见风险 | 高 | 老年组独处比例大幅高于年轻组 |
| 国籍交叉风险 | 偏见风险 | 高 | 中国老年样本中去发展化和空间压缩更明显 |
| 性别交叉风险 | 刻板化风险 | 中 | 老年女性发展导向行为较低，但家庭场景 H5b 不支持 |

## 3. 关键证据

- 发展导向行为：年轻组 48.5%，老年组 29.2%，OR=0.425，p<0.001。
- 场景压缩：年轻组 home 59.8%，老年组 home 90.3%。
- 空间压缩：老年组 indoor 89.2%，年轻组 63.5%。
- 独处：老年组 82.0%，年轻组 50.0%，OR=4.738，p<0.001。
- 科技生活符号：年轻组 91.5%，老年组 57.3%。
- 传统文化符号：年轻组 3.5%，老年组 23.8%。

## 4. 解释

即梦最显著的模式是将老年人组织进少数高度重复的语义模板：家庭、室内、独处、做饭、食物准备、阅读和日常家务。该模式对积极老龄化中的社会参与、社会连接和发展性行动构成明显张力。

## 5. 反向解释与限制

- 家庭和食物准备不天然负面；
- 部分家庭化可由日常生活 prompt 和模型风格解释；
- 需要现实证据校准老年居家、独居和社会参与差异；
- H5b 在即梦中不支持老年女性更家庭化，因此性别风险不应过度概括。

## 6. V0.5 裁决摘要

即梦在 AgingVisBench V0.5 中呈现较高的老龄偏见风险，尤其是家庭室内化、独处化、维护性活动和去现代化。它是四个模型中最适合展示“语义模板压缩”的案例之一。
