# AgingVisBench 四模型风险画像索引

**Four Model Risk Profiles**

## 1. 集合说明

本目录收录 AgingVisBench V0.5 对 GPT、Midjourney、即梦和通义四类文生图模型的风险画像。每份画像综合场景与社会位置、行动层、共鸣层及性别/国籍交叉结果，描述模型特异的老龄视觉表征模式。

模型画像不是单一偏见评分，不构成模型优劣排行榜。“总体画像”是对多个维度的自然语言概括，不是[六类裁决结果](../../docs/adjudication/risk_levels.md)之外的新增风险等级。正式判断应以逐指标风险结果、[四级证据置信度](../../docs/adjudication/evidence_confidence.md)和可靠性状态为准。

## 3. 四模型横向概览

### GPT

GPT 仍然呈现老年人的行动，但行动意义更多集中于阅读、浇花、庭院活动和日常维护，而较少连接学习、工作、创造、科技和现代公共生活。其风险重点是 development-to-maintenance compression，而不是简单的 active/passive 对立。

### Midjourney

Midjourney 是发展导向行为维度上的重要反例。它没有显示老年组发展导向下降，其风险更多通过现代符号减少、传统/医疗/家庭物体增加，以及人物更远离中心、占图像比更低等符号和构图方式呈现。

### 即梦

即梦将老年人物高度集中于家庭、室内、独处、食物准备、阅读和家务维护等少数语义模板。该模式对社会参与、社会连接和发展性行动构成张力，但独处指标仍需直接人工可靠性复核。

### 通义

通义保留较高的表面行动可见性，同时通过庭院、浇花、报纸、眼镜、碗、传统文化和医疗物体形成老龄模板。科技/传统/发展导向维度的证据较强；医疗物体维度尚未获得有效人工可靠性结果。

## 4. 如何阅读模型画像

每份模型画像通常包含：

1. 总体模式；
2. 分维度风险结果；
3. 关键统计证据；
4. 多重证据解释；
5. 反向解释与限制；
6. V0.5 裁决摘要。

阅读时应遵循以下原则：

- 风险结果和证据置信度分开理解；
- 自然语言中的“较强”“较高”是概括性描述，不是新增正式等级；
- 不根据一个指标推断模型整体；
- 不把模型特异结果扩展为全部文生图模型的普遍规律；
- 不把传统、乡村、家庭、医疗或独处符号本身定义为负面；
- H5/H6 中应区分老年组内部描述差异和正式交互效应。

## 5. 共同模式与重要例外

### 跨模型共同模式

- 四个模型均呈现老年组科技或现代生活符号减少；
- 四个模型均呈现老年组传统文化符号增加；
- 中国老年图像相较美国老年图像普遍呈现更少科技符号和更多传统符号；
- 乡村生活符号在老年图像中普遍增加，但其现实校准和正式交互结果需要分开解释。

### 重要模型例外

- Midjourney 的老年组发展导向行为高于年轻组，不能被归入主体性压缩模式；
- 即梦的家庭化和独处化最突出，但独处指标缺少直接人工可靠性结果；
- 通义的医疗物体差异较强，但测量可靠性尚未得到有效人工验证；
- 构图、BHI 和视觉氛围结果具有较强模型风格依赖性。

## 6. 可靠性边界

AgingVisBench V0.5 已完成 200 张图像的人工可靠性复核。发展导向行为、场景类型、传统文化符号和乡村生活符号达到较高一致性；科技生活符号为中等可靠性。

当前需要特别保留的缺口：

- `is_alone`：未形成直接 AI-human 一致性结果；
- `has_medical_object`：人工复核有效样本数为 0；
- BHI 与共鸣层指标：需要技术 QA，而不是语义 Kappa；
- 现实证据库仍在体系化整理，部分结论需要降低外部效度表述强度。

详情见[可靠性复核报告](../../docs/reliability/reliability_report.md)。
