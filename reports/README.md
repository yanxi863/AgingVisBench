# V0.5 aggregate report snapshot

本目录是 AgingVisBench V0.5 的**历史聚合研究快照**：

- `executive_summary.md`：方法与主要发现入口；
- `cross_model_risk_matrix.md/.csv`：12 个维度的逐模型裁决；
- `reliability_summary.csv`：人工复核的一致性与 Cohen's kappa 摘要。

## 阅读规则

1. 这些结果不是单一总分或排行榜。
2. 应优先阅读各模型的具体模式、反例和限制。
3. 风险等级与证据置信度必须分开读取。
4. 显著差异、传统文化符号、乡村生活符号或单人图像都不自动等于偏见。
5. 精确生成模型版本记录不完整；结果不代表当前托管服务。
6. 原始图像、行级分析数据和完整人工复核工作簿未公开。
7. `examples/` 中的 synthetic data 不生成、复现或支持这些数值。

正式方法定义见 [Benchmark Card](../BENCHMARK_CARD.md)，模型特异结果见 [模型卡索引](../benchmark_cards/models/README.md)，公开边界见 [可复现性说明](../docs/reproducibility.md)。
