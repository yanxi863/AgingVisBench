# 数据与隐私边界

## 数据来源

V0.5 的主要分析对象是研究期通过 ChatGPT/GPT image、Midjourney、即梦和通义生成系统获得的图像，不是真实受访者照片。生成条件包含年龄、性别、国籍和模型类型。完整 prompt、批次与模型 revision 记录并不齐全，因此公开报告被标记为历史快照。

裁决校准还参考官方统计、全国性调查、学术研究和积极老龄化理论；公开的 `evidence/real_world_evidence_template.csv` 是证据登记模板，不应被误读为已经填充完毕的完整证据库。

## 公开内容

- 安全化后的审计与处理代码；
- 指标、理论、证据和裁决文档；
- V0.5 聚合报告与模型卡；
- 不含真实模型输出的 synthetic CSV 和占位图；
- 空白证据与裁决模板。

## 不公开内容

- 原始/生成图像语料；
- 行级 CV/VLM 审计数据、checkpoint 和 stats-ready 数据；
- 人工复核工作簿、review images 和裁决者信息；
- 本机绝对路径、用户名、IDE 配置和缓存；
- API key、token、provider 响应日志；
- YOLO 等模型权重；
- 论文草稿、学校模板和其他授权状态不明的文档。

这些内容不公开并不表示它们都含个人数据；该边界同时考虑了体量、授权、可识别路径、研究完整性和第三方条款。

## 本地输出

默认本地目录 `data/`、`outputs/`、模型权重和 Office/PDF 文件均被 `.gitignore` 排除。生成的 manifest 和 CSV 可能包含绝对图像路径，不得未经检查直接上传。

## 凭据

只通过环境变量提供 `DASHSCOPE_API_KEY`。`.env.example` 只含空值；`.env` 被忽略。不要将完整环境 dump、请求 header 或 provider 原始响应写入 issue、日志或提交。

## 聚合报告

`reports/` 中的内容是经过选择的聚合研究输出。公开前，项目所有者仍需人工确认：

1. 聚合表和模型名称可公开；
2. 其中没有受限制的第三方数据；
3. 所有研究合作者认可公开范围；
4. 许可证和报告引用方式已经确定。
